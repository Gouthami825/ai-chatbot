# 🤖 AI Chatbot

A full-stack AI chatbot built with FastAPI, Google Gemini, and vanilla JavaScript.

## 🔗 Live Demo
👉 [Try it here](https://zippy-capybara-3a07a4.netlify.app)

## ✨ Features
- Real-time AI conversations powered by Google Gemini
- Multiple chat sessions with history
- Voice input support
- Markdown-formatted responses
- Mobile responsive design

## 🛠️ Tech Stack
- **Backend:** FastAPI (Python), Google Gemini API
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render (backend), Netlify (frontend)
